# Statistics Homeworks: incumbent design

The existing site and the user's request to preserve uniformity are visual authority. Homework 3 extends that established system; it does not introduce a new identity.

## Reading and interaction

Readers first learn a concept, then manipulate an example, inspect measured results and interpret their limits. Chapter introductions, numbered learning sections, local section navigation, progressive-disclosure details, data tables and exports recur in all chapters. Required and optional content in Homework 3 is explicitly labelled.

## Materials

- Warm paper background `#f8f7f2`, forest ink `#214b3c`, subdued green and terracotta for data series.
- Locally hosted Libre Caslon Display for chapter headings and DM Sans for reading and controls.
- Monospace only for mathematical encodings, point coordinates and cryptographic values.
- Existing panel borders, chart grids, typography and focus rings remain in use.
- SVG represents actual mathematical points, distributions and experiment results, rather than decorative imagery.

## Responsive behavior

The main reading area is centered with generous section spacing. Existing two-column layouts collapse into one column on narrow viewports. Long tables and scientific charts scroll inside their containers, with the surrounding explanatory text remaining within the viewport. Main navigation can scroll horizontally on small screens as chapters are added.

## Interaction states

Calculations provide loading, cancellation, validation and failure messages. Background workers keep long experiments responsive. A changed input does not silently relabel previous results. Exports record protocol parameters and corpus identifiers. Respect reduced motion and retain visible keyboard focus.

## Verification scope

Inspect the completed new chapter and navigation at desktop and mobile widths in one batched round; repair observed defects together and confirm once. Existing visual motifs specifically retained by the user's uniformity request are not grounds for a redesign.
